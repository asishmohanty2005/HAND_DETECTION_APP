## 🚀 Overview

A real-time **Hand Detection Application** built with **Python**, **OpenCV**, and **MediaPipe**.

The application detects hands from a webcam feed, tracks hand landmarks, and can be extended for gesture recognition, virtual mouse control, sign language recognition, and more.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/asishmohanty2005/HAND_DETECTION_APP.git
```

Move into the folder

```bash
cd HAND_DETECTION_APP
```

Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Run the Application

```bash
python app.py
```

# 🧠 How It Works

```text
Camera
   │
   ▼
OpenCV captures frame
   │
   ▼
MediaPipe detects hand
   │
   ▼
Extract landmarks
   │
   ▼
Draw landmarks
   │
   ▼
Display output
```
